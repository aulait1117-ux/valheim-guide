キーを自分で変えるときは必ず読むこと。 MODが33個入っているので、押しやすいキーはほぼ埋まっている。適当に変えると、 「押したら2つ同時に発動する」「別のMODが反応しなくなる」という状態になり、原因が分かりにくい。

今きれいに空いているのは、テンキーの2〜6・9くらいしかない。（I M U F9 F11 F12 は新しいMODで埋まった） それ以外はValheim本体かMODのどれかが使っている（本体側は 設定 → 操作 で確認できる）。

変えたいときは言ってもらえれば、全MODとValheim本体の割り当てを機械的に突き合わせて、 衝突しないキーを選んで設定する。自分で変えて挙動がおかしくなった場合も、同じ方法で原因を特定できる。
解消した衝突（2026-07-28）。 F1 が「高度建築モード」と「設定パネル」で二重だったので、建築モードを F2 へ移した（F1はどのMODでも設定パネルなので、そちらを残した）。 F7 も「グリッド吸着の切替」と「編集モードのリセット」で二重だったので、吸着の切替を F4 へ移した。 一人称の V はValheim本体の「自動拾い」と重なっていたので、本体側を N へ逃がした。 馬の「その場で待て」は本体のエモート（T）と、「馬鎧を外す」は本体の武器をしまう（R）と重なっていたので、 それぞれ Y と K へ移した。
これで、Valheim本体どうしの元からの重複（右クリック＝防御と建築メニュー等）を除き、衝突はゼロ。

Mods 01戦闘・コンテンツ

Therzie 5部作は互いに繋がっている。Warfare が土台で、そこに防具（Armory）・魔法（Wizardry）・敵（Monstrum）・極北（Fire&Ice）が乗る。

Warfare

Therzie / v1.8.9 日本語化済

武器を 107種・盾8種・矢/ボルト13種・蜂蜜酒3種・爆弾・つるはし2種と、弓専用の作業台を追加する。他のTherzie MODの土台。

何が増えるか
  • バニラに無い武器種：ウォーパイク（突撃槍）、ランス、グレートボウ（超遠距離弓）、両手バスタードソード、クレイモア、投げ斧、クロスボウ、二刀流
  • 両手武器の攻撃モーションが作り直されている。バニラの両手武器は使いにくかったが、これでちゃんとした選択肢になる
  • バトルアックス・大槌・フェンリルの爪はWarfare版に置き換わる（元のレシピはワールド読み込み時に無効化される）
  • 矢と弓は新しい「矢師の台（Fletcher table）」で作る。的も建てられる
ボスからの限定ドロップ
  • エルダー → 戦鎚（4%）
  • エイクスュル → クロスボウ（4%）
  • モデル → グレートボウ（6%）
  • ヤグルース → 刃（7%）
  • シーカークイーン → 篭手（8%）

Armory

Therzie / v1.3.1 日本語化済

バニラの防具を強化版に作り替えるためのMOD。専用の作業台「武具工房」を建てて、そこで既存防具をアップグレードする。

使い方
  • 武具工房を建てる。鍛冶場と同じ拡張パーツでレベルを上げると、上位レシピが解放される
  • 強化した防具は次のバイオーム向けにさらに強化していける。装備を捨てずに育てる形
  • 溶解炉と収納チェストが内蔵されている
セット効果（自分の戦い方を選ぶ）
  • ラゾルバック＝アトゲイル・槍スキル＋スタミナ回復／ハンター＝刺突ダメージと弓・クロスボウ
  • ローグ＝ナイフ／ヴィゴラス＝斧／ウォリアー＝棍棒／ヴィーザル＝剣／ボールド＝アトゲイル／レギオン＝槍
  • フェンリル＝素手。このサーバーは素手ダメージが70に上げてあるので相性がいい
  • スタッグ＝移動速度とジャンプ距離
一部の防具は Monstrum の敵が落とす素材を使う。Monstrumも入っているので普通に作れる。

Wizardry

Therzie / v1.1.8 日本語化済

魔法を本格化させる。属性魔法の杖5種・血の魔法の杖2種・魔導士セット5種、新しい魔法の敵、エイトル food、ポーション、スクロールを追加。

使い方
  • ウィザードテーブルとその拡張を建てるところから始まる
  • 杖はバイオームごと（黒い森・沼・山・平地・ミストランド）＋ゴーレム・サートリング
  • 魔法のサークレット（額冠）が5系統ある：エイトル回復／属性強化／狩人／隠密。青銅〜甲殻まで素材違いで用意されている
  • 指輪もバイオームごとに5種
  • モンスターを召喚して戦わせられる
魔法用の素材（魔法の木材・ボスの破片・毛糸・生地・巻物）は新しい魔法の敵が落とす。魔法をやるなら敵を狩る流れになる。

Monstrum

Therzie / v1.5.1 日本語化済

新しいモンスター11種とミニボス3体を追加。倒すとWarfare・Armoryのレシピに必要な素材とトロフィーが手に入る。

増える敵
  • キツネ、ラゾルバック（猪の上位）、ツキノワグマ、灰色小人の古代シャーマン、クローラー、ヘルレイス、腐ったヘラジカ、ハイイログマ、黒曜石ゴーレム、プラウラー、サメ
  • ミニボス3体：アスモデウス／スヴァルト／ヴリコラサス。専用の祭壇で召喚する（ヴェグヴィシルで場所が分かる）
テイムできる
  • 新しい生物の一部は手懐けられる。手懐けたら MountUpRestored の鞍を着ければ乗れる
  • キツネ・クマ用の毛皮の敷物も建てられる
新しいミニボスの祭壇は「新しく生成された土地」にしか出ない。今のワールドの既に探索済みの場所には湧かないので、まだ行っていない方へ探検すると出会える。

Warfare: Fire & Ice

Therzie / v2.0.8 今回追加日本語化済

未完成だった極北（Deep North）に植生と素材を入れ、炎・氷・雷を宿した最上位武器を追加する。今回の目玉。

まずやること
  • 極北へ行き、ティラニウム鉱石（氷）とラグノライト鉱石（炎）とロクヴィルを掘る
  • ユミルの鍛冶場を建てる。ここが全ての起点。拡張として「ニョルズのなめし台」「ロクヴィルの溶解槽」「ソラダスの鍛造槌」「ルーン球」が付く
  • ドヴェルグの溶解炉を建てると、あらゆる金属を通常より速く精錬できる
武器の系統
  • ニョルズ系＝氷（敵を凍らせる）／スルト系＝炎（燃やす）。ほぼ全ての武器種に両系統がある
  • 特殊武器：氷河／溶岩／雷光の双刃、クロムの嵐斧、スカジの双剣、憤怒と憎悪、スヴィガとフレック、ストームストライク・ハンマー
  • 魔法：ヴァルカリオンの憤怒（炎）、スクリューミルの凍気（氷）、嵐呼びの杖（雷）
  • 虚無呼びの杖＝悪魔を召喚。狼の心臓＝ストームウルフを召喚。召喚した仲間には名前が付く
  • 爆弾3種（炎・氷・雷）、爆発する矢とボルト
極北で採れるもの
  • 食料：ツンドラベリー、ウィンターキャップ（キノコ）、原初のネギ。どれも苗から育てられる
  • 木：北方樹・北方マツ。松ぼっくりから植えられる
  • 素材：ウルサの毛皮、プライドタスクの毛皮、アイスストーカーの鱗、ダイアウルフの毛皮、黒氷、ヨトゥンの歯／眼球
極北にはまだ敵がいない。 このMODは地形と素材だけを足すもので、モンスターは別MOD（Monstrum Deep North）の担当。 入れていないので、極北は危険が少ない代わりに手応えも薄い。欲しければ追加できる。

Epic Loot

RandyKnapp / v0.12.15 最初から日本語

ディアブロ的なレアリティ付きの装備を追加する。敵と宝箱から「マジック → レア → エピック → レジェンダリー → ミシック」の装備が落ちる。

レア度と、このサーバーでの出現率
  • レア度は下から マジック → レア → エピック → レジェンダリー → ミシック の5段階
  • 2026-07-28、全96のドロップ表に「レジェンダリー 0.1%・ミシック 0.02%」の下限を入れた。 元は雑魚から出る可能性が0だったので、どんな敵からでも、極めて低い確率だが出るようになった
  • 星なしの雑魚は「そもそも何も落とさない」設定だったので、0.5%の下限も入れた。 つまり星なしの灰色小人からレジェンダリーが出る確率は 0.5% × 0.1% ＝ 0.0005%（20万体に1体）
  • 敵のレベルが上がるほど確率は跳ね上がる。星3なら「30%で何か落ちる × その1%がレジェンダリー」＝ 0.3%
  • つまり強い敵を狩るほど本命が出るが、雑魚からの一発逆転もゼロではない
レジェンダリーを宝箱の中身として直接入れることはできない。 EpicLootのレジェンダリーは「アイテムそのもの」ではなく装備に後から付く称号なので、 宝箱の抽選表に「レジェンダリーの剣」と書くことができない。 だからドロップ表の確率のほうを引き上げる形で対応した。
仕組み
  • 魔法の装備には魔法効果が複数付く。装備すると効果が乗る
  • エンチャント台を建てると、装備の強化・分解・再構成ができる
  • ルーン：未鑑定のアイテムが落ちる → エンチャント台で鑑定。既存の魔法装備を生贄にして効果をルーン石に取り出し、別の装備に付け替えられる
  • アビリティが付いた装備は G H J で発動

CreatureManager

sighsorry / v1.1.2 今回追加日本語化済

敵に32種類の強化をランダムで付ける。さらに「同じ場所で狩り続けると土地が荒れる」カルマという仕組みを持ち込む。 猪の体力バーの下に出る小さいアイコンが、その敵の付いている強化。

強化のつき方
  • 強化は攻撃／防御／弱体／特殊の4群。1体につき各群から最大1つ＝最大4つまで付く
  • このサーバーでは1つあたり8%の確率（2026-07-28に5%から引き上げた）。執行者だけは10%とさらに当たりやすい
特に気をつける強化
  • 回避不可：ローリングの無敵をすり抜けてくる（代わりに威力25%減）。盾とパリィは通常どおり効く
  • 死の守り：とどめの一撃を打ち消して体力20%で復活する（1体3回まで）
  • 渦：矢や魔法を50%で完全に無効化する。遠距離だけで倒そうとすると詰む
  • 適応：一度受けたダメージ種を覚えて50%軽減する。武器を持ち替えると通る
  • カメレオン：10秒ごとに無敵になる属性が切り替わる
  • 瞬間移動：16m以内から一瞬で寄ってくる（警戒されてから3秒は使ってこない）
  • 刈り取り：近くの生物が死ぬたびに体力・攻撃力・体格が上がっていく
  • 猛毒の死：倒した瞬間、半径4m以内に最大体力の30%の毒をばらまく
カルマ（この地域はどれだけ荒れているか）

  • まとめて収納（P）：その物が既に入っている箱にだけ入る。だから拠点で押せば勝手に片付く
  • 補充（L）：矢・食料などを近くの箱から満タンまで戻す。出かける前に押す
  • 並べ替え（O）：名前・価値・重さ・種類から選べる
  • 捨てる（Delete）：持っている物を捨てる。「捨てる」印を付けた物をまとめて捨てることもできる
お気に入り（これが肝）
  • Alt＋左クリックでアイテムを、Alt＋右クリックで枠をお気に入りにする
  • お気に入りにした物は収納・並べ替え・全部しまう・捨てるの対象外になる。ハンマーや大事な装備を守れる
「捨てる」印の付け方
  • 持ち物を開くとゴミ箱が出る。捨てたいアイテムをゴミ箱の上に重ねた状態で Alt＋左クリックすると「捨てる」印が付く
  • 印を付けておくと、Delete で印の付いたものだけをまとめて捨てられる（毎回選ばなくていい）
  • 設定でトロフィーを常に「捨てる」扱いにすることもできる

Notes知っておいてほしいこと

全員が同じMODでないと入れない

  • MODを1つでも足したり消したりすると、他の人は「バージョンが異なります」で弾かれる。だから追加はサーバー・ホスト・参加者を同時に更新する必要がある
  • 3者が揃っているかは毎回スクリプトで機械的に照合している。今は28個すべて一致
  • 配布するのは Valheim_MOD一式.zip（1,629MB・日本語訳と説明書を同梱）。Discordは25MB上限なのでギガファイル便で渡す

MODを入れた「あと」から始めたワールドではない

  • 今のワールドは既に広く探索されている。新しい素材と場所は「まだ行っていない土地」にしか湧かない
  • 該当するもの：Monstrumのミニボス祭壇、FineWoodPiecesの葦・粘土・粘土採掘場、Fire&Iceの極北の植生
  • つまり遠出すると新要素に当たる。逆に拠点周りだけ回っていても何も変わらない

スタック上限を後から下げると物が消えることがある

  • 今は4倍（木なら200個まで1スタック）。これを後から2倍に戻すと、上限を超えている分が失われうる
  • 下げたくなったときは先に言ってほしい。世界のバックアップを取ってからにする
